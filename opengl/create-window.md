# 창 만들기 (준비하기)

**주의: 이 글에서는 창을 띄우는게 아닌, 컴파일까지만 합니다.**

우리가 아무리 간지나는 (멋진) 3D 게임을 만들게 되더라도,
일단 그릴 화면이 있어야 그리겠죠?
이번엔 그 그릴 화면을 띄우기 위한 준비를 해봅시다.

창을 만드는게 간단하다고 생각하시나요?

**"당연하죠. 유치원생도 할거에요"**

만약 파이썬을 쓰신다면 그럴겁니다.
파이썬은..
```python
import tkinter as tk

window = tk.Tk()

window.title("내 첫 번째 창")

window.geometry("400x300")

window.mainloop()
```
이렇듯 매우 쉽고 이지하게 끝납니다.
하지만 그건 언제나 **파이썬**의 얘기입니다.
OpenGL은 훨씬 더 복잡해요.

OpenGL은 창을 만드는게 운영체제마다 다르다는 점 때문에 직접 창을 만들어주지 않습니다.
그래서 창을 생성하고, 컨텍스트를 정의하고, 사용자 입력을 처리하는 모든 것들을 다 저희가 해야해요.
근데 그걸 다 하면 진짜 접어도 뭐라 할 말이 없거든요?
하지만 운 좋게도 그걸 편하게 제공해주는 라이브러리들이 꽤나 많습니다!
이제 걔네들이 귀찮은걸 다 해준다는 말이기에, 우리는 그냥 적절한 라이브러리나 쓰면 됩니다.

**대표적인 OpenGL 라이브러리**

| 이름 | 특징 | 사용 |
| --- | --- | --- |
| GLUT | 오래되고 한계 있음 | x |
| SDL | 너무 무겁고 OpenGL 전용이 아님 | x |
| SFML | C++ 전용이고 자체 2D 때문에 충돌 | x |
| GLFW | 가볍고 OpenGL, Vulkan 전용 | o |

위 표와 같은 이유 때문에, GLFW를 사용할겁니다.
하지만 다른 라이브러리를 써도 되긴 합니다.
설정이 비슷하긴 할겁니다.

## GLFW

GLFW는 오로지 OpenGL 같은 그래픽 API를 위한 라이브러리입니다.
C로 작성돼서 다른 언어로 바인딩이 쉬워요!
(그래도 Python에서도 OpenGL이 가능하답니다)
GLFW는 렌더링을 하는데 필수적인 것들을 제공을 해줍니다.
그래서 OpenGL 컨텍스트 생성, 윈도우 설정, 사용자 입력 처리 등을 처리할 수 있는데,
이정도면 튜토리얼 완료하기에 부족함이 없습니다!

이제부터 GLFW 환경 구축부터 링킹까지 할건데,
원본은 Visual Studio를 사용하지만 저는 VS Code를 사용하므로 설명이 부실할 수 있습니다.

## GLFW 빌드하기

GLFW는 [공식 사이트](https://www.glfw.org/download.html)에서 다운로드가 가능합니다.
사이트엔 이미 컴파일된 바이너리와, 소스 패키지가 있는걸 볼 수 있습니다.

바이너리를 바로 써도 되긴하지만 이번엔 GLFW를 컴파일 할겁니다. 그러면 오픈소스 라이브러리를 직접 컴파일 하는 과정을 맛볼 수 있고, 라이브러리들이 바이너리를 제공하지 않아 컴파일이 필요할때 도움이 될 수도 있습니다.

이제 소스 패키지를 다운로드 합시다!

하지만 우리는 딱 이것만 보면 됩니다.

그래서 CMake를 쓰면 더 편합니다.

## CMake

CMake는 자기만의 코드를 읽고 그거에 맞게 컴파일 해주는 자동화 도구?라고 보시면 됩니다.
CMake는 [여기](https://cmake.org/download/)서 받을 수 있고, 다운로드하고 설치해주세요.

설치를 다 했으면, 이제 설정을 해야합니다.
CMake에는 소스코드 폴더와 컴파일 결과를 넣을 폴더가 필요합니다. 소스코드 폴더는 GLFW 소스 패키지의 루트 폴더 하시면 돼고 빌드 폴더의 경우엔 새 폴더 build를 생성한 다음 사진처럼 디렉터리를 선택합니다.
![사진1](/assets/opengl/cmake.png)

소스코더 폴더와 빌드 폴더가 세팅된 후에는 Configure 버튼을 클릭해서 CMake가 필요한 설정과 소스 코드들을 읽을 수 있도록 하고,
프로젝트 생성자를 지정해야 하는데 원본은 Visual Studio 2019를 사용하고 있으므로 Visual Studio 16 옵션을 선택합니다.
CMake는 결과 라이브러리를 구성할 수 있는 빌드 옵션을 표시할텐데, 기본값을 그대로 두고 다시 구성을 클릭하여 설정을 저장합니다.
설정이 완료되면 생성 버튼을 클릭했을때 빌드 폴더에 새 프로젝트 파일이 생성됩니다.

## 컴파일

build 폴더 안을 보면 GLFW.sln이라는 파일이 생성되어 있을 겁니다. 이 파일을 Visual Studio 2019로 열어줍니다.
CMake가 이미 기본 설정이 적용된 프로젝트 파일을 생성해주었기 때문에, 별다른 설정 없이 그냥 솔루션을 빌드(build)하기만 하면 됩니다.
CMake는 기본적으로 이 솔루션이 64비트 라이브러리로 컴파일되도록 자동 설정했을 겁니다. 이제 솔루션 빌드(Build Solution) 버튼을 클릭하세요.
그러면 build/src/Debug 폴더에 glfw3.lib라는 이름의 컴파일된 라이브러리 파일이 생성됩니다.
라이브러리를 생성한 뒤에는 IDE가 OpenGL 프로그램에 필요한 라이브러리와 포함 파일의 위치를 ​​알 수 있도록 해야 합니다.
이를 위한 접근 방식은 크게 두 가지입니다.

1. IDE 또는 컴파일러의 /lib 및 /include 폴더를 찾아서 GLFW의 include 폴더 내용을 IDE의 /include 폴더에 추가하고, 마찬가지로 glfw3.lib 파일을 IDE의 /lib 폴더에 추가합니다. 이 방법은 작동은 하긴하지만 권장되는 방법은 아닙니다. 라이브러리 및 include 파일의 위치를 ​​추적하기 어렵고, IDE나 컴파일러를 새로 설치할 때마다 이 과정을 반복해야 하기 때문입니다.

2. 권장하는 방법은 IDE 또는 컴파일러에서 참조할 수 있는 라이브러리의 헤더 파일/라이브러리를 모두 담을 새 폴더 세트를 원하는 위치에 만드는 겁니다. 예를 들어, OpenGL 프로젝트에 필요한 모든 라이브러리와 헤더 파일을 각각 저장하는 **Libs** 폴더와 **Include** 폴더가 포함된 폴더를 만들 수 있습니다. 이렇게 하면 모든 라이브러리가 단일 위치(여러 컴퓨터에서 공유 가능)에 정리됩니다. 단, 새 프로젝트를 만들 때마다 IDE에 해당 디렉터리의 위치를 ​​알려줘야 한다는 점을 주의해야 합니다.

## GLFW 바이너리 적용하기

주의: 이 부분은 CMake를 하고 나면 필요가 없는 내용입니다. 아래 제목이 나올때까지 스크롤하세요.

역시나 설정이 귀찮으셨죠?
그래서 우리는 뭐 설정들을 하지 않고 컴파일 명령어로 퉁칠겁니다.

**가장 중요!!! 컴파일 명령어는 Windows만 말할겁니다. 리눅스나 MacOS에선 작동 안합니다.**

일단 [여기](https://www.glfw.org/download.html)에서 바이너리를 받아주세요. (64비트로)

그리고 이제 압축을 풀고, 아래대로 해주세요.
1. 다운로드 한 폴더 안의 include 폴더로 가서 GLFW 폴더를 통째로 복사합니다.

1-1. 프로젝트 폴더의 include 폴더 (없으면 만드세요)에 붙여넣기 합니다.

2. lib-mingw-w64 폴더의 libglfw3.a 파일 한 개를 복사합니다.

2-1. 프로젝트 폴더의 lib 폴더 (없으면 만드세요22)에 붙여넣기 합니다.

전체 프로젝트 구조

```
project/
├── include/
│   ├── glad/
│   ├── KHR/
│   └── GLFW/
├── lib/
│   └── libglfw3.a
└── src/
    ├── glad.c
    └── main.cpp
```

이러면 끝납니다. 컴파일할때는 이런 명령만 넣으면 돼요.

``` g++ src/main.cpp src/glad.c -o main.exe -Iinclude -Llib -lglfw3 -lopengl32 -lgdi32 -luser32 ```
